# Café Mios: Schaubilder „Das ist möglich"

**Zweck:** Beim Gespräch zeigen, wie hochwertig Frühstücksbilder aussehen können. Das sind **Beispielbilder für das Gespräch**, keine Fotos vom Buffet des Cafés. Bitte nicht als „unser Essen" veröffentlichen und dem Café ehrlich sagen: „Das ist die Bildqualität, die wir mit euren echten Zutaten und einem Drehtag erreichen wollen."
Jedes Bild bekommt unten klein die Zeile „Beispielbild" (im Prompt enthalten), damit es nie als echtes Foto durchgeht.

Reihenfolge in **einem** ChatGPT-Chat. Grundprompt aus `../chatgpt-sortiert/00-Grundprompt-zuerst/prompt.txt` zuerst einfügen. Logo nur bei Bild 6 anhängen.

## Look für alle (einmal vorab einfügen)
```
Für diese Reihe gilt ein Look: warmes Morgenlicht von links durch ein Fenster, weiche Schatten, leichte Tiefenunschärfe, dunkle Holztische, silberne Tabletts, Tee im Tulpenglas, Oliven, Tomaten, Gurken, Käse, Sesamkringel (Simit), Börek, Menemen in der Kupferpfanne, Honig, Marmelade. Wände dunkelgrün, Messing-Details, Terrakotta-Boden. Fotorealistisch wie ein Food-Magazin, natürlich, nicht überzüchtet: keine glänzende Plastikoptik, keine Fantasieobjekte, keine Schrift im Bild, keine Personen. Hochformat 4:5 (1080×1350) wenn nicht anders genannt.
```

## 1) Das große Tablett (Draufsicht)
```
Draufsicht auf einen dunklen Holztisch, zwei silberne Tabletts mit kleinen Schälchen (Oliven, Tomaten, Gurke, Weißkäse, Honig, Marmelade, Sucuk), Simit und gekochtes Ei, daneben zwei Tulpengläser Tee. Warmes Fensterlicht von links, leichte Dampfwolke über dem Tee. Sehr aufgeräumt, viel dunkle Fläche links für späteren Text.
```

## 2) Tee einschenken (Nahaufnahme)
```
Nahaufnahme: dunkler Tee wird aus einer Kanne in ein Tulpenglas eingeschenkt, Dampf steigt auf, im Hintergrund unscharf ein Tablett mit Frühstück. Gegenlicht vom Fenster, Messing-Schimmer. Querformat 16:9.
```

## 3) Der Börek-Schnitt
```
Seitliche Nahaufnahme: ein goldbrauner Börek auf Holzbrett wird mit einem Messer aufgeschnitten, Blätterteig knusprig, ein Hauch Dampf. Im Hintergrund unscharf ein grüner Raum mit Messing-Barhockern. Hochformat 9:16.
```

## 4) Das Buffet im Morgenlicht
```
Weitwinkel auf ein langes kaltes Frühstücksbuffet mit weißem Tuch: Schalen mit Oliven, Käse, Aufschnitt, Salaten, Teigtaschen, Brot, Honigwaben. Dunkle grüne Wand dahinter, warmes Seitenlicht, leichte Tiefenunschärfe. Keine Warmhalte-Behälter aus Metall, keine Menschen. Querformat 16:9.
```

## 5) Zwei am Tisch (nur Hände)
```
Zwei Personen frühstücken am Fenster, nur Hände und Teller sichtbar, ein Stück Simit wird geteilt, Tee in Tulpengläsern, Morgenlicht. Gesichter nicht zeigen. Ruhige, warme Stimmung. Hochformat 4:5.
```

## 6) Titelbild „Frühstück für zwei"
Anhängen: `logo-cafe-mios.webp`
```
Hochwertiges Werbebild für ein Café-Gewinnspiel, 4:5. Im Vordergrund ein Tablett mit Frühstück für zwei auf dunklem Holz, daneben eine creme-farbene Gutscheinkarte mit dem angehängten Logo (Logo exakt wie angehängt, sonst nichts auf der Karte). Warmes Fensterlicht, grüne Wand unscharf dahinter. Unten klein, in heller Serifenschrift: „Beispielbild". Sonst keine Schrift.
```

## Nach den Bildern
- Rechtschreibung der kleinen Schrift prüfen. Wenn ChatGPT Fantasie-Schrift auf Teller oder Wand malt: „Alle Schrift im Bild entfernen, außer ‚Beispielbild'."
- Nicht verwenden, was komisch aussieht (verschmolzene Finger, zu viele Gabeln, unmögliche Teller). Lieber neu würfeln lassen.

## Kleine Animation (Ideen, was daraus werden kann)
Standbild wird zu 5–8 Sekunden Loop für Reel/Story:
1. **Dampf und Licht** über Tee und Tablett, minimale Kamerafahrt nach vorn.
2. **Tiefenparallax** (leichte 3D-Bewegung im Bild, wie eine langsame Kamerafahrt).
3. **Tee-Einschenken** mit realer Bewegung.

Wege:
- **A) Ohne Credits (von mir):** Dampf, Lichtwechsel und sanfte Kamerafahrt aus dem Standbild, sauber und dezent. Gut für Bild 1, 3, 4. Nicht Hollywood, aber seriös und sofort verfügbar.
- **B) Mit Higgsfield (Credits):** echte Bewegung, z. B. Tee fließt, Dampf wirbelt. Erst auf Elias' Okay mit konkretem Preis (vorher Kosten abfragen, kein Verbrauch ohne Freigabe).
- **C) ChatGPT:** erzeugt nur Standbilder, keine Videos.
